# HikingApp

## Описание проекта

HikingApp — серверная часть приложения для организации туристических походов.

Приложение позволяет пользователям создавать походы, просматривать доступные маршруты, подавать заявки на участие и управлять своими походами.

## Используемые технологии

- **Node.js** — серверная среда выполнения.
- **Express.js** — создание API и обработка HTTP-запросов.
- **PostgreSQL** — реляционная база данных.
- **Sequelize** — ORM для взаимодействия с базой данных.
- **JWT** — авторизация пользователей.
- **bcrypt** — хеширование паролей.
- **dotenv** — хранение конфигурационных переменных.
- **CORS** — настройка взаимодействия с другими источниками.

## Основные возможности

- Регистрация и авторизация пользователей.
- Получение и редактирование профиля.
- Создание, просмотр, изменение и удаление походов.
- Поиск и фильтрация походов.
- Подача заявок на участие.
- Просмотр собственных заявок.
- Управление заявками организатором.
- Проверка прав доступа пользователей.
- Валидация входных данных.
- Централизованная обработка ошибок.

## API Endpoints

Базовый адрес API: `http://localhost:5000/api`

### 1. Пользователи (`/users`)

| Метод | Endpoint | Описание | Авторизация |
|---|---|---|---|
| POST | `/users/register` | Регистрация | Нет |
| POST | `/users/login` | Авторизация | Нет |
| GET | `/users/profile` | Получение профиля | Да |
| PATCH | `/users/profile` | Изменение профиля | Да |

### 2. Походы (`/hikes`)

| Метод | Endpoint | Описание | Авторизация |
|---|---|---|---|
| GET | `/hikes` | Получение списка походов | Нет |
| GET | `/hikes/:id` | Получение похода по ID | Нет |
| POST | `/hikes` | Создание похода | Да |
| PUT | `/hikes/:id` | Изменение похода | Да |
| DELETE | `/hikes/:id` | Удаление похода | Да |

Поддерживается фильтрация походов по региону, сложности, дате и названию.

### 3. Заявки (`/applications`)

| Метод | Endpoint | Описание | Авторизация |
|---|---|---|---|
| POST | `/applications` | Создание заявки | Да |
| GET | `/applications/my` | Просмотр своих заявок | Да |
| GET | `/applications/organizer` | Просмотр заявок организатора | Да |
| PATCH | `/applications/:id/status` | Изменение статуса заявки | Да |
| DELETE | `/applications/:id` | Отмена собственной заявки | Да |

### Авторизация запросов

Для защищённых маршрутов необходимо передавать JWT-токен в заголовке:

```http
Authorization: Bearer YOUR_TOKEN
```

Токен получается при успешной авторизации пользователя.

## Запуск проекта

1. Установить зависимости:

```bash
npm install
```

2. Настроить переменные окружения в файле `.env`.

3. Запустить сервер:

```bash
npm run dev
```

Сервер запускается на порту 5000.
